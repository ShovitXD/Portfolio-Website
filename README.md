# Portfolio frontend

A local React project powered by Vite.

## Run the site

Open a terminal in `E:\Projects\Portfolio Website` and run:

```sh
npm install
npm run dev
```

Open the local address printed by Vite. While the server runs, saving changes to your files updates the page automatically.

## Project files

- `src/main.jsx` is the React entry point and currently contains the starter page.
- `index.html` contains the browser title and page description.
- `package.json` lists the packages and commands for this project.

## Production build

```sh
npm run build
```

This creates the production site in `dist/`. Use `npm run preview` to check that build locally.

The personal design and portfolio content are pending your role and preferences.
